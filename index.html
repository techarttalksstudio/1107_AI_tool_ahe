01

AI 與偏見

關於今天提到的 AI 與偏見，延伸補充一段三分鐘影片給大家，大家可以額外搜尋「Algorithmic Bias」去看背後的運作機制。

Ethics & AI: Equal Access and Algorithmic Bias（英文影片，可開啟字幕）· 影片無法播放時，點這裡到 YouTube 觀看

AI 的原理是把看過的大量資料重新組合，挑出「最有可能」（多數決）的答案。而「最有可能」這個概念其實就跟話語霸權有關係。

刻板印象

譬如請 AI 畫「工程師」「護理師」「校長」，人物的性別、年齡、外貌往往很一致。

語言與文化霸權

網路上英文與歐美觀點的內容占多數，問節慶、飲食、歷史時，預設答案常不是我們的在地經驗。

被忽略的聲音

在網路上資料少的社群、語言與地方文化，AI 回答時容易出錯，因為資料過少。

02

p5.js 除錯方式

在 p5.js 線上編輯器 按下執行後，如果畫面沒出來，看下方的 Console（主控台）有沒有紅字。以下三步驟：

步驟 1

先說明要做的功能

讓 AI 知道你的目標，它才判斷得出程式哪裡跟目標不一樣。

步驟 2

把錯誤訊息複製給 AI

Console 的紅字整段複製，連同目前的程式碼一起貼上。

步驟 3

修正後再執行

貼回 AI 給的程式碼，還有錯就重複步驟 2。

提示詞範本：修正錯誤
我用 p5.js 想做的功能是：【例如：聲音變大時，畫面換成另一張圖片】

目前的程式碼如下：
【貼上程式碼】

執行後出現這個錯誤訊息：
【貼上 Console 的紅字】

請告訴我錯誤的原因，並給我修正後的完整程式碼。

想細部調整？請 AI 告訴你要改哪個數值

功能做出來後，要調大小、顏色、速度、門檻，不用每次都請 AI 重寫。請它指出是哪一段的哪個數值，自己動手改。

提示詞範本：找出要改的數值
請說明這段 p5.js 程式碼中，控制【圓的大小／顏色／移動速度／音量門檻】的是哪幾個數值？
請列出：在第幾行、目前的數值、改大或改小會發生什麼變化。
【貼上程式碼】

常見的錯誤訊息

錯誤訊息通常的原因
... is not defined變數或函式名稱拼錯，或大小寫不同（mouseX 寫成 mousex）。
Unexpected token / missing )括號 ( ) { } 沒有成對，或少了逗號。
p5.AudioIn is not a constructor沒有載入 p5.sound 函式庫。請 AI 告訴你怎麼在 index.html 加上 p5.sound。
沒有紅字，但麥克風沒反應瀏覽器沒有允許麥克風權限，或還沒點一下畫面啟動聲音。
03

如何把 HTML 變成可以分享的網頁

AI 幫你寫好的 HTML 檔，存在電腦裡只有你看得到。放到 CodePen 或 GitHub Pages，就會得到一個網址，學生用手機、平板點開就能用。

  1. 註冊並登入 CodePen

    到 codepen.io，可以用 Google 或 GitHub 帳號直接登入。

  2. 新增一個 Pen

    點左側或右上角的 Create → Pen，畫面會出現 HTML、CSS、JS 三個欄位，下方是預覽畫面。

  3. 把 AI 給的程式碼貼進 HTML 欄

    如果 AI 給的是一整份檔案（裡面已經有 <style> 和 <script>），整份貼進 HTML 欄就可以，CSS、JS 欄留空沒關係。

  4. 取名並儲存

    點左上角的鉛筆圖示改名稱，再按 Save。

  5. 複製網址分享

    儲存後網址列就是分享連結。想給學生看全螢幕、不顯示程式碼的版本，把網址中的 /pen/ 改成 /full/。

小提醒免費帳號的 Pen 是公開的，別放學生的真實姓名或個資。
  1. 註冊並登入 GitHub

    到 github.com 註冊。帳號名稱會出現在網址裡，建議取好記的英文名稱。

  2. 建立一個新的儲存庫（Repository）

    點右上角 + → New repository，取一個英文名稱（例如 seat-chart），選 Public，按 Create repository。

  3. 上傳 HTML 檔

    點 uploading an existing file 或 Add file → Upload files，把檔案拖進去。檔名一定要是 index.html，最後按 Commit changes。

  4. 開啟 GitHub Pages

    進入儲存庫的 Settings → Pages，在 Build and deployment 的 Source 選 Deploy from a branch，Branch 選 main 和 / (root)，按 Save。

  5. 等一兩分鐘，拿到網址

    重新整理 Pages 頁面，上方會出現網址，格式是 https://帳號.github.io/儲存庫名稱/。

要修改時再上傳一次同名的 index.html 覆蓋就好，網址不會變，學生手上的連結繼續可以用。

4-3聲音變大，花朵盛開

聲音越大，花開得越大；也可以換成圖片，聲音越大圖片越大。適合用在拍手、合唱、喊口號的活動。這頁無法使用麥克風，先用滑桿模擬音量。

p5.js 程式碼：聲音越大，花朵開得越大（點開查看）
p5.js 麥克風版本 · 貼到 editor.p5js.org 的 sketch.js
// 聲音越大，花朵開得越大
// 確認 index.html 有載入 p5.sound；執行後點一下畫面，允許麥克風

let mic;
let level = 0;         // 平滑後的音量
let started = false;

function setup() {
  createCanvas(640, 400);
  mic = new p5.AudioIn();
  angleMode(DEGREES);
  textAlign(CENTER, CENTER);
}

function mousePressed() {
  if (!started) {
    userStartAudio();
    mic.start();
    started = true;
  }
}

function draw() {
  background(255, 248, 240);
  if (!started) {
    fill(0);
    textSize(24);
    text('點一下畫面開始', width / 2, height / 2);
    return;
  }

  level = lerp(level, mic.getLevel(), 0.2);
  // 音量 0 ~ 0.3 對應到花朵大小 30 ~ 300，想更敏感就把 0.3 改小
  let size = map(level, 0, 0.3, 30, 300, true);

  // 花莖
  stroke(60, 140, 70);
  strokeWeight(8);
  line(width / 2, height / 2, width / 2, height);

  // 花瓣：每 36 度畫一片，共 10 片
  noStroke();
  push();
  translate(width / 2, height / 2);
  fill(240, 100, 150);
  for (let a = 0; a < 360; a += 36) {
    push();
    rotate(a);
    ellipse(0, size * 0.35, size * 0.35, size * 0.7);
    pop();
  }
  fill(255, 200, 0);
  circle(0, 0, size * 0.35);   // 花心
  pop();
}

4-4聲音變小，改變畫面

用麥克風偵測教室音量，安靜時畫面變好看、太吵時畫面改變。可以直接用現成的網站，也可以用 p5.js 自己做。

直接用現成網站

Field Watch

p5.js 程式碼：聲音變大聲／變小聲，換不同圖片（點開查看）
p5.js 麥克風版本 · 貼到 editor.p5js.org 的 sketch.js
// 聲音變大聲 → 換成 loud 圖片；聲音小 → 換成 quiet 圖片
// 1. 在編輯器左側上傳兩張圖片，檔名改成 quiet.png、loud.png
// 2. 確認 index.html 有載入 p5.sound（沒有的話請 AI 教你加）
// 3. 執行後點一下畫面，允許麥克風

let mic;
let quietImg, loudImg;
let vol = 0;            // 平滑後的音量
let threshold = 0.1;    // 門檻：數字越小越敏感（0 ~ 1）
let started = false;

function preload() {
  quietImg = loadImage('quiet.png');
  loudImg = loadImage('loud.png');
}

function setup() {
  createCanvas(640, 400);
  mic = new p5.AudioIn();
  textAlign(CENTER, CENTER);
}

function mousePressed() {
  if (!started) {
    userStartAudio();   // 瀏覽器規定要點一下才能開始收音
    mic.start();
    started = true;
  }
}

function draw() {
  background(240);
  if (!started) {
    fill(0);
    textSize(24);
    text('點一下畫面開始', width / 2, height / 2);
    return;
  }

  // lerp 讓音量變化平滑，畫面不會一直閃
  vol = lerp(vol, mic.getLevel(), 0.2);

  if (vol > threshold) {
    image(loudImg, 0, 0, width, height);
  } else {
    image(quietImg, 0, 0, width, height);
  }

  // 下方的音量條，紅線是門檻
  noStroke();
  fill(vol > threshold ? 'red' : 'green');
  rect(20, height - 30, map(vol, 0, 0.3, 0, width - 40, true), 12);
  stroke(0);
  let tx = map(threshold, 0, 0.3, 20, width - 20);
  line(tx, height - 36, tx, height - 12);
}

4-5用 AI 進行 3D 建模、製作 2.5D 遊戲

下面是一個 2.5D（等角視角）小遊戲範例：用方向鍵或按鈕移動，避開方塊，收集星星。

星星：0 / 5

AI 3D 建模的流程

  • 文字或圖片轉 3D：用 Meshy、Tripo 這類工具，輸入描述或上傳學生的手繪圖，產生 3D 模型。
  • 下載模型檔：常見格式是 .glb / .obj，可以放進網頁或 3D 列印軟體。
  • 請 AI 寫展示網頁：用 Three.js 讓模型在網頁上旋轉、縮放。

2.5D 遊戲的做法

  • 2.5D 是什麼：用斜 45 度的視角畫 2D 圖，看起來有立體感，但程式比真正的 3D 簡單。
  • 先做小關卡：地圖、角色移動、一個目標，能玩了再加功能。
  • 除錯照第 02 段：說明功能、貼錯誤訊息、問要改哪個數值。
